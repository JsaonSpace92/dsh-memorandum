# 备忘录 · dsh-memorandum

为 DeepSeek Harness 提供左侧栏**每日重要事件（当日清单）与全局常驻备忘（全取清单）**管理插件。安装后在左侧栏显示中文名称 **备忘录**（位于「会话清理」下方，`order: 50`），支持在任意对话或任务中**选中文字直接右击添加为备忘录**。界面采用克制的卡片排版、衬线标题与 DSH 原生亮暗主题自适应变量。

## 核心功能

| 模块 | 功能说明 |
| --- | --- |
| **1. 左侧栏「备忘录」入口** | 注册在 `sidebar.panellist`（`id: "dsh-memorandum"`, `order: 50`），点击切换至中央主面板 `main` |
| **2. 选中文字右击「添加备忘录」** | 在对话或任务面板中全选/框选任意文字后右击，点击 **「添加备忘录」** 即可选择 **「1. 当日清单」** 或 **「2. 全取清单」** 一键入库 |
| **3. 当日清单（`daily`）** | 按日期（`YYYY-MM-DD`）记录当天重要事件，内置 7 日微缩状态周历条、当日焦点提要与环形完成率 |
| **4. 全取清单（`evergreen`）** | 跨日期长期保留的全局常驻备忘、核心规范与长期跟进事项，不随日期切换而消失 |
| **5. 状态与顺延管理** | 支持勾选已完成/未完成、重要度分级（`重要` / `常规` / `随手`）、分类标签、置顶、行内编辑、长文本展开/复制，以及往日未完成事项一键顺延至今日 |
| **6. Agent 协同工具** | 注册 `memorandum` 工具，支持在对话中直接让 Agent 查询、新增、勾选完成、顺延或整理备忘事项 |

## 对话选中文字右击添加流程

1. 在 DeepSeek Harness 任意对话或任务输出中，鼠标框选或全选一段文字并**右击**；
2. 弹出右键菜单，显示已选字数预览、**「添加备忘录」**与**「复制选中文本」**；
3. 点击 **「添加备忘录」**，展开两个目标选项：
   - **1. 当日清单**：记入今日重要事件（`scope: "daily"`）；
   - **2. 全取清单**：记入全局常驻备忘（`scope: "evergreen"`）。
4. 单行短文本直接作为标题；多行或长段文字自动提取首行摘要作为标题，并将完整原文保存在备注中（支持在备忘录卡片中一键「展开全文 / 收起全文」与「复制全文」）。
5. 添加成功后右下角弹出提示，点击 **「打开备忘录 →」** 即可直接跳转到对应备忘清单。

## 安装与测试

可通过 DSH CLI 或内置 `plugin_manager` 安装：

```bash
dsh plugin --profile desktop add github:JsaonSpace92/dsh-memorandum
```

或在本地克隆仓库后，使用 DSH `plugin_manager` 的 `install_bundle`（`target` 设为本地仓库目录路径）安装。

```bash
npm run check
npm test
```
