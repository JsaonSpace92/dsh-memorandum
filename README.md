# dsh-memorandum

DSH 左侧栏的备忘录插件：一处记下**当日事项**和**常驻事项**，往日没做完的可以一键顺延；在对话里选中文字后右击，就能把它记入备忘。

## 功能

- **看板视图**：「今天」和「常驻」两栏并排；窗口较窄时自动改为上下排列。另有当日、常驻、历史三个单栏视图。
- **快速输入**：在输入框里直接回车添加；句首写 `!` 标为重要，写 `#标签` 设为分类，例如 `! 发布 v0.3 #研发`。
- **当日焦点**：给每一天写一句最重要的事。
- **周历条**：前后 7 天一目了然，圆点表示未完成、重要和已完成的数量。
- **跨日顺延**：往日未完成的事项会集中提示，可以全部或逐条顺延到今天，并标记「顺延自」。
- **全局搜索**：跨所有日期搜索标题、备注和分类。
- **撤销**：删除和清理已完成之后，6 秒内可以撤销。
- **键盘操作**：`N` 新建，`/` 搜索，`[`、`]` 切换日期，`T` 回到今天；行内编辑时 `⌘↵` 保存，`Esc` 取消；在 DSH 任意位置按 `⌘⇧M`（Windows/Linux 为 `Ctrl+Shift+M`）打开备忘录。
- **多端同步**：通过 AI 工具或对话右键写入的内容，会自动刷新到面板。
- **AI 工具 `memorandum`**：模型可以查询、新增、完成、编辑、删除、顺延、清理事项，以及设置当日焦点；返回结果是精简的可读文本，不会把整份数据塞进上下文。

## 对话选区右键：不会覆盖复制

v0.3 起不再在全局拦截右键，而是接入 DSH 官方的对话文本交互接口（`uiConversation.interactions`）：

| 场景 | 行为 |
| --- | --- |
| 在对话正文中选中文字，并在选区上右击 | 弹出菜单：**复制**、**引用到输入框**、记入今天的备忘、记入常驻备忘 |
| 在对话正文中左键选中文字 | 不做处理，官方的「引用」浮动按钮照常出现 |
| 输入框、文件树、终端、设置页等其他区域 | 完全不做处理，保留系统原生菜单（撤销、剪切、复制、粘贴、全选）和官方右键菜单 |
| 不想要这个菜单 | 在面板底部关闭「对话选区右键记入备忘」开关 |

当前 DSH 版本中，对话正文选区右键由插件菜单处理，菜单提供复制和可用时的引用操作。其他区域的右键不由本插件拦截。DSH 后续版本可能调整交互接口或菜单行为，升级后需要重新验证兼容性；如有冲突，可关闭面板底部的右键开关。

## 数据

- 默认存放在 `$DSH_HOME/dsh-memorandum/memorandum-data.json`（通常是 `~/.dsh/dsh-memorandum/`），与插件包目录分开，升级或重装插件都不会丢数据。
- 首次启动时，如果新位置还没有数据，会自动从旧版位置 `<插件目录>/runtime/memorandum-data.json` 复制过来；旧文件会保留。
- 每天第一次写入前，会自动备份到 `backups/memorandum-YYYY-MM-DD.json`，保留最近 14 份。
- 可以在 `cordis.patch.yml` 中用 `dataDir`、`timeZone`（默认 `Asia/Shanghai`）覆盖默认值。

## 安装

```bash
dsh plugin --profile desktop add github:JsaonSpace92/dsh-memorandum
```

安装或更新之后，需要完全退出并重新打开 DSH。

## 开发

```bash
npm run check   # 语法检查
npm test        # 单元测试与 Host 集成测试
```

- `core.js`：数据层（存储、迁移、备份、查询）。
- `index.js`：Host 端，提供 HTTP 路由（`/memorandum/v1`）和 AI 工具。
- `client.js`：Web 端，包括侧栏入口、主面板、对话选区菜单和快捷键。
- 修改 `client.js` 后刷新 DSH 页面即可生效；修改 `index.js` 或 `core.js` 后需要重启 DSH。
